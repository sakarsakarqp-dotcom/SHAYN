# SHAYN | شين

منصة تجارة إلكترونية عربية لاكتشاف المنتجات والعروض والمتاجر والتواصل مع البائعين، مع أقسام متنوعة تشمل الأزياء والإلكترونيات والمنزل والجمال والسيارات والخدمات.

هذا هو المستودع الأساسي المعتمد للنشر: `sakarsakarqp-dotcom/SHAYN`. لا تطوّر النسخة المكررة `shayn-syria`.

## المتطلبات
- Node.js 20 أو أحدث
- PostgreSQL متاح عبر اتصال TLS في بيئة الإنتاج
- `DATABASE_URL`
- `JWT_SECRET` عشوائي لا يقل عن 32 محرفاً
- `ADMIN_PASSWORD` قوي عند إنشاء حساب المدير الأعلى لأول مرة

## عزل قاعدة البيانات المشتركة
- يستخدم ATHAR المخطط الحالي `public` في Supabase دون تغيير.
- يستخدم SHAYN مخططاً مستقلاً اسمه `shayn` عبر اتصال PostgreSQL مباشر، مع `search_path=shayn` حتى لا يقرأ أو يكتب جداول ATHAR.
- عند تشغيل `npm run db:init` تنفّذ التهيئة ترحيلاً حذراً: إذا وجدت الجداول الستة المعروفة لـ SHAYN في `public` وبنية أعمدتها مطابقة، تنقلها مع بياناتها إلى `shayn`. إذا وجدت مجموعة جزئية أو بنية مختلفة أو تعارضاً في المخطط الهدف، تتوقف برسالة خطأ ولا تنقل أي جدول.
- لا تشغّل التهيئة على قاعدة الإنتاج قبل التأكد من وجود نسخة احتياطية حديثة وإمكانية استعادتها.

## التشغيل المحلي
```bash
npm install
cp .env.example .env
# املأ القيم محلياً ولا ترفع ملف .env إلى GitHub
npm run db:init
npm start
```
افتح `http://localhost:3000`. فحص الاتصال: `/api/health`.

## النشر
يمكن نشر التطبيق على أي استضافة تدعم Node.js 20 أو Docker:
1. اربط هذا المستودع الأساسي بخدمة الاستضافة.
2. استخدم Dockerfile أو أمر التشغيل `npm start`.
3. أضف متغيرات البيئة من `.env.example` في لوحة الاستضافة فقط.
4. أنشئ قاعدة PostgreSQL وخذ رابط الاتصال مع TLS.
5. اضبط أسرار قاعدة البيانات و`JWT_SECRET` و`ADMIN_PASSWORD` في الاستضافة.
6. عند بدء الخدمة، يهيّئ التطبيق مخطط SHAYN والجداول والترحيلات الإضافية تلقائياً قبل استقبال الطلبات. اضبط فحص الصحة على `/api/health`.
7. اختبر التسجيل والدخول والمنتجات وصورها والبحث والتواصل والبلاغات ولوحة المدير قبل الإعلان.
