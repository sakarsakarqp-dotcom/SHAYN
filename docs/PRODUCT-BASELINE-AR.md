## 2. المستودع المرجعي والواقع الموجود في main
المستودع المرجعي هو sakarsakarqp-dotcom/SHAYN. ويطلب README عدم تطوير النسخة المكررة shayn-syria.

تم التحقق من الملفات التالية في main:
- التطبيق Node.js 20 وExpress وPostgreSQL عبر pg.
- الواجهة النشطة في public/index.html وpublic/app.js وpublic/style.css.
- مصادقة بريد وكلمة مرور باستخدام bcrypt وJWT.
- نموذج إعلانات مشترك للأنواع job وproject وservice وmarket، مع business أضيف عبر الترحيل 005.
- مسارات للتقديم والرسائل والتقييمات والبلاغات والإدارة.
- سلة متصفح وطلبات شراء أولية في PostgreSQL؛ الطلب الحالي يدعم بائعاً واحداً وعملة واحدة، ولا يجمع أموالاً إلكترونياً.
- مخطط قاعدة البيانات المنفصل shayn، وترحيلات حتى 006.
- فحص npm run check يتحقق من صياغة JavaScript، ولا يثبت وحده سلامة التشغيل أو التكامل أو النشر.

## 4. الفجوات الحالية بين main والرؤية
1. جدول users في main يحمل دور منصة واحداً؛ الأدوار المهنية المتعددة موجودة فقط في ترحيل PR #4 غير المدمج.
2. لا توجد في main واجهات API مكتملة لإنشاء المؤسسات أو دعوة الأعضاء أو إدارة عضوياتهم وصلاحياتهم.
3. الوظائف والمشاريع والخدمات ما زالت تعتمد إلى حد كبير على نموذج الإعلان المشترك، ولا تملك جميعها دورات العمل المستقلة المطلوبة.
4. السوق يملك طلب شراء أولياً، لا مخزوناً متكاملاً أو دفعاً أو تسوية أو تتبع شحن.
5. البلاغات والتقييمات أولية؛ لا يوجد نظام مكتمل لتوثيق الحسابات والشركات أو إدارة النزاعات والأدلة والاستئناف.
6. لا توجد اختبارات طرف إلى طرف أو مراجعة أمنية شاملة مثبتة في هذا التدقيق.
7. يوجد تعارض توثيقي يحتاج حسمه: README_AR يذكر 30 مجالاً رئيسياً و360 فرعاً، بينما قائمة CATEGORY_NAMES التي تمت مراجعتها في server.js تعرض مجموعة أصغر؛ لا يعتمد أي عدد نهائي قبل استخراج التصنيفات آلياً ومقارنتها بالواجهة والبيانات.
8. README وملفات الحالة لا تصف دائماً الرؤية المتكاملة ذات الوحدات الخمس بالصياغة نفسها؛ يلزم توحيد التوثيق بعد اعتماد PRD.

## 5. المتطلبات العليا المستهدفة
- حساب شخصي واحد، وأدوار مهنية متعددة مستقلة عن صلاحيات إدارة المنصة.
- ملف مهني مناسب لكل دور دون تكرار الحساب.
- مؤسسة لها ملف مستقل ومالك وأعضاء ودعوات وصلاحيات وسجل تدقيق.
- ملكية كل إعلان أو وظيفة أو مشروع أو خدمة أو منتج واضحة: شخص أو مؤسسة.
- دورات عمل منفصلة للوظائف والمشاريع والخدمات والسوق.
- Trust للتوثيق والبلاغات والتقييمات المؤهلة والنزاعات والإجراءات.
- إدارة مركزية للتصنيفات والمحتوى والحسابات والمؤسسات والبلاغات.
- واجهة عربية RTL أولاً، مع تصميم لا يربط البيانات بدولة أو عملة واحدة.
